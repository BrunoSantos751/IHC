# # São Longuinho - Sistema de Achados e Perdidos

Projeto desenvolvido para a disciplina de **IHC (Interação Humano-Computador)**.

###  Sobre o projeto

O sistema tem como objetivo facilitar o **registro, busca e localização de objetos perdidos dentro da faculdade**.

Atualmente, quando um aluno encontra um objeto, pode ser difícil localizar o proprietário. A proposta busca tornar esse processo mais **simples, rápido e intuitivo**, utilizando princípios de **UX/UI**.

###  Foco do projeto

* Experiência do usuário (UX)
* Interface do usuário (UI)
* Usabilidade
* Facilidade de navegação
* Acessibilidade

###  Tecnologias

* Figma
* UX/UI Design.
